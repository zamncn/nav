关于本站

Chenn 的导航 · 一个简单的导航页

感谢来访。这是一个自用的上网导航，把平时要跑的站点按用途分类收在一页里， 打开浏览器就能直接开工，省得在收藏夹里翻来翻去。

本站承诺

不会收集你的隐私信息。区别于部分导航站，这里的链接直接跳转目标，不做中转再跳转； 页面也不埋任何统计脚本，点击记录、访问记录、搜索记录一概不留。

怎么用

  • 左边是分类栏，鼠标停在图标上会浮出分类名，点左上角按钮可收起或展开。
  • 顶部中间是搜索框，选好引擎后回车即搜。
  • 右上角切换深色 / 浅色，选择记在浏览器本地，下次进来还是它。
  • 想把它当首页：按 Ctrl+D 收藏，再到浏览器设置里设为启动页。

技术说明

纯静态页面，HTML / CSS / JavaScript 三件套，没有后端也没有数据库， 托管在 GitHub Pages 上。页面模板来自开源项目 WebStackPage（MIT 许可）。
